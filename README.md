# Quote Hub

chat crie um projeto, de cotão de pedidos. Estilo o codigo anexo. Só preciso que você coloque, na parte de cotação, vou colocar o assunto, a cotação, e você vai me dar um planilha e pdf editavel para enviar aos fornecedores, para eles colocarem os precos, e toda cotação ficará salva com a possibilidade de baixar planilha, com o assunto da cotação, a data enviada, e o material que foi enviado e a quantidade de peças
